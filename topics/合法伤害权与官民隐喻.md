# 合法伤害权与官民隐喻

> 从吴思的两句话出发，推演到「掠夺如何可持续」的统治术总纲。核心命题：**官与民的隐喻不是"强者吃弱者"，而是"捕食者与资产"——狼的真正难题从来不是怎么吃羊，而是怎么一直有羊可吃。**

## 起点：两条原始文本

1. 吴思《[[潜规则]]》：「合法地祸害别人的能力，乃是官吏们的看家本领。」
2. 吴思《[[血酬定律]]》（狼羊段）：「我不吃，别的狼照样吃……我的自我约束对羊群来说没有意义，徒然减少自己的份额。」

---

## 第 1 站：这两句话的内核

关键词不是"祸害"，是「**合法**」。非法祸害 = 犯罪；合法祸害 = 权力。

[[合法伤害权]]的三要素（缺一不可）：

| 要素 | 作用 |
|------|------|
| **合法** | 提供免责（没有它，是流氓不是官吏） |
| **伤害** | 提供威慑 |
| **选择** | 提供租金（最关键，最易被忽略） |

- 推论：**权力大小 = 能造成的、且不必负责的损失的大小。**
- 核心规律：**模糊是权力的母体。规则越含糊 → 自由裁量越大 → 合法伤害权越大。**
- 反证：规则精确到无选择余地（税额定死、强制限期办结）→ 无权力可寻租。

---

## 第 2 站：现代案例

官吏身份在现代基本消失，但本领换了三件马甲：

1. **行政裁量**（嫡系）：消防/环保/城管检查、审批拖延、处罚幅度（同一违规罚十倍差）
2. **平台与算法**（新型官吏）：应用商店审核下架、电商"二选一"（阿里被罚 182 亿）、封号限流
   - 特殊性：连"官府"都不是，不受行政法约束，连"谁在伤害你、依据哪条"都拿不到
3. **组织内部**（微观版）：审批卡点、资源分配先后、绩效裁量、一票否决

**结论**：现代性没有消灭合法伤害权，而是把它**从"人的裁量"搬进"系统的裁量"**。人可问责，系统不能。

---

## 第 3 站：底层原因（是人性吗？）

人性是**表层答案**，是同义反复，只解释"缝被谁利用、往哪用"。往下三层：

| 层 | 内容 | 性质 |
|----|------|------|
| 人性层 | 决定缝的利用方向 | 填充物，非容器 |
| 契约层（[[不完全契约]]） | 任何契约都写不全，留白 = 裁量空间 | 信息问题，非道德问题 |
| 数学层（[[Ashby必要多样性定律]]） | 有限规则 vs 无限现实 | 必然，不是缺陷 |

- 第 3 层即：管理者信息处理能力**必有限**，被管理世界复杂性**必无限** → 永远存在管不到的自由度。
- 同一件事的三次复述：[[哥德尔不完备定理]]（数学）· Ashby（控制论）· 吴思（历史）。
- 定性：**权力是结构给的，腐败是人性选的。**
- 更深悖论：**明规则无法自我奠基**（规则需解释 → 解释需人 → 人有裁量 → 又生潜规则，无穷倒退）。[[维特根斯坦]]：遵守规则是一种实践。
- 结论：**潜规则不是明规则的敌人，是明规则的地基。**

---

## 第 4 站：狼羊的囚徒困境

狼的推理 = [[囚徒困境]]中的**占优策略**（无论别人怎么选，"吃"的收益都更高）→ [[搭便车]]（奥尔森《集体行动的逻辑》）。

- **它是"对的"**——这是最可怕处：个体理性，集体非理性。
- 但它**偷藏了一个条件句**："如果我的节制不能导致别人的节制"——默认了"100% 无法影响别人"。
  - 该假设取决于博弈结构：**单次博弈成立；重复博弈不成立**（[[阿克塞尔罗德]]：以牙还牙能自发长出合作）。
- 毒点：把「**协调失败**」伪装成「**自然规律**」。是自我实现的预言，用集体困境为个体选择开脱。
- 出路只有两条，都**不靠狼变善良**：
  1. 有牙齿的第三方（[[霍布斯]]/[[利维坦]]）：事先交出咬人能力 → 合作被强制成占优
  2. 改变博弈本身（阿克塞尔罗德）：重复、未来重要、违约可识别可罚
- 更深悖论：牧羊人就是最大的狼 → [[血酬]]自我循环。

---

## 第 5 站：代入官与民

- **官版：成立**。官员是同构竞争者，争同一只羊。清官困境：我不贪，别人照贪，份额归别人。且清官的存在破坏掠夺均衡，**系统会碾碎他**。
- **民版：断裂**。羊**没有"吃"这个选项**。民只能说"我不被吃，别人照样被吃"。
  - 差异：**狼 = 决策，羊 = 宿命；狼有选择权，羊无。**
- 但民在用**同构的句法填别的空**：我不送礼/不找关系/不举报 → 孩子输/名额让人/挨整的是我。
- 关键：囚徒困境**在道德上中性**——既是掠夺者的刀，也是被掠夺者的药。结构不站队。
- 它的功能是一台**免责机器**：狼/官/民，一句话三张证明，都抹掉了主语"我"。
- **最狠的洞察**：民不是羊，是**想变狼的狼**。潜规则无阶级性；民恨它常因自己不是受益者。
  - "分而治之"不是政策，是同一困境套在羊群上的**自动结果**。羊开始互咬，狼不必动手。
- **破坏长期博弈的元凶：[[流官制]]**。任期一到就调走 → 对土地未来产权为零 → 掠夺成理性。
  - 现代版：空降高管、任期短期主义、只认任内 KPI。
- 民的三张牌：**退出 / 呼吁 / 反抗**。当退出与呼吁被堵死 → [[弱者的武器]]（斯科特）→ 血酬高过忍耐 → **农民起义**。
- **血酬的终点不是"狼吃羊"，是"羊变狼"** → 王朝周期律。

---

## 第 6 站：狼要一直有羊吃，该怎么做（统治术总纲）

**零阶原则**：羊是**资产**，不是猎物。
- 捕猎 = 零和，吃存量（[[流寇与坐寇|流寇]]）；养殖 = 正和，吃增量（[[流寇与坐寇|坐寇]]）。

**致命陷阱**：单只狼做不到"留种"。
- 我节制 → 羊群恢复 → 收益大家分；我多吃 → 份额立刻到手。
- [[公地悲剧]] → 理性决策在无协调时自动实现不了，必须有更高力量介入。

**关键跃迁**：从捕猎者 → **收租者**。
- 狼王抽租 → 羊变成**狼王的私有财产** → 狼王反而有了**保护羊的动机**。
- 奥尔森：流寇变坐寇，是文明的第一缕光。

**牧羊三支柱**：

1. **造故事**（合法性）：君权神授、"父母官" → 给吃羊发许可证
2. **分甜头**（收编精英）：让部分羊先肥，科举收编最聪明的羊 → 羊变"牧羊犬"，上了桌就不再掀桌
3. **定规矩**（秩序）：**表面护羊，实为狼群的和平协议**

**反直觉处**：规矩不只管羊，**更是管狼**。狼群真正的死法只有三种，全与羊无关——**内斗 / 失控 / 继承**。立规矩是为防狼群内斗把羊群一起拖死。

**养羊技术**：养肥（发展经济）、多养（人口）、改良（教育技能）、**数清**（编户齐民/保甲/征信/大数据）。
- 最后一条是一切统治术的地基：**想吃得准，先数得清**（鱼鳞图册 → 算法画像，同一动作）。

**甜蜜的诅咒**：每一次"养"，都同步提升羊造反的能力。
- 要产出 → 羊识字会算 → 羊会思考；要效率 → 给自由 → 手腕硬。
- **[[托克维尔定律]]：压迫最狠时不闹，放松管制时才革命**。期望是被唤醒的。

**终局**：唯一解是收到"羊饿不死、也吃不饱"的程度。但这是**移动的瞬间，不是稳态**：

- 收太狠 → 羊变狼（起义）
- 收太松 → 狼群内斗（分裂）
- 恰到好处 → 盛世（短暂）
- **王朝周期律的真身：不是狼坏，是这套系统的稳态解不存在。**
